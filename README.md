# ethos

## Development database

The dev/test database runs in Docker on port 54329 (host Postgres is broken
on this machine, so the app doesn't use the default 5432). Start it with
`docker compose up -d`, which brings up the `ethos-pg` container
(`postgres:16`, password `postgres`, named volume `ethos-pg-data`) matching
the connection settings in `config/dev.exs` and `config/test.exs`.

## Deploying

The repo ships the Fly.io deployment artifacts (`Dockerfile`, `.dockerignore`,
`fly.toml`, `rel/`, `lib/ethos/release.ex`) generated by
`mix phx.gen.release --docker`, with `libvips-dev`/`libvips42` added to the
Dockerfile's builder/runner `apt-get install` lines (required by `vix` for OG
card image generation). No `fly` commands have been run against this repo —
deployment is a manual step a human runs from a machine with `flyctl`
installed and authenticated.

Note: OG card PNGs are written to `priv/uploads/`, which is ephemeral on Fly.
That's acceptable for v1 — cards regenerate on next publish, and existing
cards survive until the next redeploy.

### First-time launch

```bash
fly launch --no-deploy          # accept app name "ethos" (or edit fly.toml), skip auto-deploy
fly postgres create --name ethos-db
fly postgres attach ethos-db    # wires DATABASE_URL into the app's secrets
fly secrets set ANTHROPIC_API_KEY=<key> EXA_API_KEY=<key>
fly deploy
```

`config/runtime.exs` already reads `DATABASE_URL`, `SECRET_KEY_BASE` (set by
`fly launch`), `ANTHROPIC_API_KEY`, and `EXA_API_KEY` from the environment.

### Migrate and seed production

```bash
fly ssh console -C "/app/bin/ethos eval 'Ethos.Release.migrate()'"
fly ssh console -C "/app/bin/ethos eval 'Code.eval_file(\"/app/lib/ethos-0.1.0/priv/repo/seeds.exs\")'"
```

### Manual smoke checks

1. Landing page loads and shows the seeded Lisbon guide.
2. Register, create a guide, paste a dump, confirm entries, publish — parse +
   enrichment work with live keys.
3. Public guide link unfurls with the OG card (test in an OG debugger, e.g.
   opengraph.xyz).
4. Suggest a place from a second account; accept it; credit line renders.
5. Research button returns fresh results and rate-limits after 10 clicks.
